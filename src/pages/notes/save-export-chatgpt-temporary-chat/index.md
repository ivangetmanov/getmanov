# How to Save or Export a Temporary Chat in ChatGPT

## Short answer

Save a useful Temporary Chat before you leave it. OpenAI says Temporary Chats do not appear in history unless you choose to save them, so do not rely on finding an unsaved chat later. You can save it to history, create a local TXT copy, print it as PDF, or copy it into your notes.

## How to save a Temporary Chat before you leave it

1. While the Temporary Chat is still open, decide whether you need it in ChatGPT history or as your own file.
2. Save it in ChatGPT if you want it to become a regular conversation in your history.
3. Create a local TXT export if you want searchable, editable Q&A notes.
4. Use Print → Save as PDF when a static reading copy is enough.
5. Copy-paste only short chats; verify that every prompt and response made it across.

| Method | Best for | Limitation |
| --- | --- | --- |
| Local TXT export | Searchable, reusable notes | Not a visual document |
| PDF | A readable static copy | Weak for editing and Q&A reuse |
| Copy-paste | A short chat | Easy to miss content in long chats |

OpenAI's current Temporary Chat guidance says that unsaved Temporary Chats do not appear in history, while saving converts the chat into a regular chat. [Read the official Temporary Chat FAQ](https://help.openai.com/en/articles/8914046-temporary-chat-faq).

## How to export a Temporary Chat as TXT

With the Temporary Chat open, use [ChatGPT Session Saver](/tools/session-saver/) to extract the active conversation into local TXT/Q&A notes. The extension has been manually verified against an active Temporary Chat. Give the file a descriptive name and store it somewhere searchable before you close the tab.

## Temporary Chat retention vs your own local copy

OpenAI may retain an unsaved Temporary Chat for safety purposes for up to 30 days, but that is not the same as a personal archive you can search and reuse. A local file is your working copy; a saved Temporary Chat becomes a regular chat in your history.

## FAQ

### Can you save a Temporary Chat in ChatGPT?

Yes. OpenAI says you can save a Temporary Chat to history, which converts it into a regular chat. You can also keep your own local copy before leaving.

### Can you export a Temporary Chat?

Yes. Export the active conversation to a local TXT file, print it to PDF, or copy it manually before leaving.

### Do Temporary Chats appear in history?

Not unless you choose to save them.

### What happens when you close a Temporary Chat?

If you did not save it, do not treat it as a normal history item you can reopen later. Keep a local copy first if it matters.

### Can you save a Temporary Chat as TXT?

Yes. A local TXT workflow preserves a searchable copy of the active conversation.

### Can you save a Temporary Chat as PDF?

Yes. Use your browser's Print dialog and choose Save as PDF for a static copy.
