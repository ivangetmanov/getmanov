# How to Download a Full ChatGPT Conversation

## Short answer

To download one complete ChatGPT conversation, use a local TXT export when you want to search and reuse the chat, or use Print → Save as PDF when you want a readable static copy. A Shared Link is useful for viewing, while official Data Export is for account-wide data rather than one current thread.

| Method | Best for | What you get |
| --- | --- | --- |
| Local TXT export | Search, editing, and Q&A reuse | Local text file |
| PDF | Reading, archiving, sharing | Static document |
| Copy-paste | Short chats | Manual text copy |
| Shared Link | Showing a conversation | URL |
| Official Data Export | Account backup | ZIP with account data |

## How to download one full ChatGPT conversation

1. Open the complete conversation you want to keep.
2. Pick the format by job: TXT for reuse, PDF for layout, or a shared link for access.
3. For TXT/Q&A notes, use [ChatGPT Session Saver](/tools/session-saver/) while the active chat is open.
4. For a PDF, open your browser print dialog and choose Save as PDF.
5. Verify the first and last messages are included before you close the conversation.

TXT is better when the conversation will become working material: you can search, edit, split, and move it into a knowledge base. PDF is better when you primarily need a stable visual record.

## One conversation vs all ChatGPT data

Official Data Export is the right method for an account-level archive. It is not a one-click download for the current chat; OpenAI's export arrives as a ZIP containing chat history and other account data. [Read the official Data Export instructions](https://help.openai.com/en/articles/7260999-how-do-i-export-my-chatgpt-history-and-data).

## FAQ

### How do I download one full ChatGPT conversation?

Save the active chat as local TXT, print it to PDF, copy it manually, or create a shared link. Use Data Export for account-level data.

### Does ChatGPT Data Export download one chat only?

No. It is an account-level export, so it is not the fastest way to keep one complete current conversation.
