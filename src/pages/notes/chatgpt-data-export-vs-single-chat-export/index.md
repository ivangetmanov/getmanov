# ChatGPT Data Export vs Single-Chat Export: What's the Difference?

## Short answer

Use **ChatGPT Data Export** when you need a broader copy of eligible account data. Use a **single-chat export** when you only need one conversation now. They solve different jobs: the official export arrives as a ZIP and can take time; a local TXT, PDF, or copy can be kept immediately for one active chat.

| Method | Scope | Best use | Output | Do you need to find the chat afterward? |
| --- | --- | --- | --- | --- |
| Official Data Export | Account-level | Backup and records | ZIP with chat history and other account data | Usually, yes |
| Shared Link | One shared conversation | Letting someone view it | URL | No, but it is not a local file |
| PDF | One current conversation | Readable archive or sharing | PDF | No |
| Local TXT export | One current conversation | Search, editing, and reuse | TXT | No |

OpenAI documents Data Export as a request for eligible account data through Settings or the Privacy Portal; the ZIP can include chat history and other account data, and the request can take up to seven days. [Read OpenAI's current Data Export instructions](https://help.openai.com/en/articles/7260999-how-do-i-export-my-chatgpt-history-and-data).

## When official Data Export is the right choice

Choose official export when your goal is a broad account archive, a privacy request, or a record that includes more than one conversation. It is not designed as a quick “download this one chat” workflow.

## When single-chat export is the right choice

Choose a single-chat method when you have one useful conversation open and want to keep it without unpacking and locating it in an account archive.

| Goal | Best option |
| --- | --- |
| Share a viewable conversation | Shared Link |
| Keep a static, readable copy | PDF |
| Keep editable, searchable notes | Local TXT export |
| Back up account data | Official Data Export |

[ChatGPT Session Saver](/tools/session-saver/) is the local TXT/Q&A option for one active conversation. It is useful when preserving the question-and-answer flow matters more than creating an account-wide archive.

## Shared Link vs local file export

A shared link is for access, not ownership. OpenAI says personal-account shared links can be opened by anyone who has the link, so review the conversation before sharing. A local TXT or PDF file is the better choice when you need your own reusable copy rather than a URL another person can open or forward. [Read OpenAI's Shared Links guidance](https://help.openai.com/en/articles/7925741-chatgpt-shared-links-faq).

## Best option by goal

* Use **Official Data Export** for account-level data.
* Use a **Shared Link** to show one conversation to another person.
* Use **PDF** to preserve the visual reading layout.
* Use **Local TXT export** to search, edit, and reuse one active conversation.

## FAQ

### Is ChatGPT Data Export the same as exporting one conversation?

No. Data Export is an account-level download. A single-chat export is for keeping one specific conversation in a practical format.

### Is a shared ChatGPT link a local export?

No. A shared link is a URL for viewing shared content. It is not a local reusable file.
