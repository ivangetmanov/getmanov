# How to Save a ChatGPT Conversation as PDF

## Short answer

Browser **Print → Save as PDF** is usually the simplest way to create a readable static copy of one ChatGPT conversation. It is good for archiving or sharing a finished chat. Use local TXT instead when you need searchable, editable notes rather than a visual document.

## How to save a ChatGPT conversation as PDF

1. Open the conversation you want to keep.
2. Use your browser's Print command.
3. Choose **Save as PDF** as the destination.
4. Confirm the page range and layout, then save the file.
5. Open the PDF once to confirm that the beginning and end of the chat are included.

## PDF vs TXT vs Shared Link vs Data Export

| Method | Best for | Limitation |
| --- | --- | --- |
| PDF | Readable archive and sharing | Awkward for editing and Q&A reuse |
| TXT | Search, editing, and knowledge reuse | Does not preserve the visual layout |
| Shared Link | Letting someone view the chat | Not a local document |
| Official Data Export | Account-level records | Not a PDF and not a quick one-chat workflow |

Use [ChatGPT Session Saver](/tools/session-saver/) when the conversation needs to become searchable, editable local text rather than a static PDF. For formats beyond PDF, see [TXT vs Markdown vs PDF vs JSON for ChatGPT Export](/notes/chatgpt-export-formats-txt-markdown-pdf-json/).

## What PDF preserves and what it does not

PDF preserves a readable layout and makes a stable reference easy to archive or send. It is less suitable for pulling out individual Q&A pairs, reorganizing text, or building a knowledge base from a long conversation.

OpenAI's Data Export is an account-level ZIP, not a native PDF export. [Read the official Data Export documentation](https://help.openai.com/en/articles/7260999-how-do-i-export-my-chatgpt-history-and-data).

## FAQ

### Can I save one ChatGPT conversation as PDF?

Yes. Browser Print → Save as PDF is usually the simplest way to keep a readable static copy of one conversation.

### Is PDF better than TXT for a long ChatGPT chat?

PDF is better for reading and static reference. TXT is better for searching, editing, and reuse.

### Does official ChatGPT Data Export create a PDF?

OpenAI describes Data Export as a ZIP of chat history and other account data, not a PDF export workflow.
